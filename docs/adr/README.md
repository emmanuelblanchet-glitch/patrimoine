# ADRs — décisions d'architecture

Une décision mérite un ADR si elle réunit les trois critères de la charte :
**dure à inverser** + **surprenante** (un nouveau venu ne la devinerait pas)
+ **vrai arbitrage** (il existait une alternative sérieuse).
