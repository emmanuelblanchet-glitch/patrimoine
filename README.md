# Patrimoine

Assistant personnel de gestion de patrimoine (chantier PATRIMOINE-01).
Outil d'une seule personne, construit avec le sérieux d'un outil
professionnel : bilan net, échéanciers, calendrier des engagements,
fiscalité à paramètres datés, puis poche financière, risque et veille.

- Carte du projet et garde-fous : `CLAUDE.md`
- Glossaire : `CONTEXT.md` · Décisions : `docs/adr/` · Cadrage : `docs/cadrage-lot-0.md`
- Vérifier : `npm run verifier` (validateur d'état + tests, Node ≥ 24, zéro dépendance)

Le dépôt ne contient jamais de données : la base vit hors git (ADR-0002).
